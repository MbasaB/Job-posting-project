# Job Posting Project

A software development project exploring how a web interface could help job seekers browse opportunities and organise their job-search activities.

## Project overview

The goal was to explore a job portal with basic features such as job listings, account forms, document upload and interview scheduling.

## Related source code

The browser-based **Nexus — Job Portal Prototype** is available here:

**[View the Nexus prototype source code](https://github.com/MbasaB/tes)**

That repository contains HTML, CSS and JavaScript files, along with instructions for running the prototype locally and a clear explanation of which functions are demonstrations.

## Repository status

This repository currently contains project documentation only. For the implementation and working front-end files, see the linked Nexus prototype.
